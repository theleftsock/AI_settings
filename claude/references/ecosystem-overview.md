# Claude ecosystem components

> Overview of the separate products/surfaces that make up the Claude ecosystem, for orientation when deciding what belongs in this settings repo.

## End-user apps

| Component | What it is |
| :--- | :--- |
| **claude.ai (web app)** | Browser chat interface. Includes Projects, Artifacts, and Claude Code's web surface at claude.ai/code |
| **Claude Desktop** | Native Mac/Windows app. Chat + MCP server support + "cowork" agentic features. Config in `~/Library/Application Support/Claude/` (macOS) |
| **Claude mobile apps** | iOS/Android chat apps |

## Developer / coding tools

| Component | What it is |
| :--- | :--- |
| **Claude Code (CLI)** | Terminal-based agentic coding tool — the `claude` command. Config in `~/.claude/` and `~/.claude.json` |
| **Claude Code — VS Code extension** | IDE integration; runs Claude Code inside VS Code (native extension, not just terminal-in-editor) |
| **Claude Code — JetBrains extension** | Same, for JetBrains IDEs (IntelliJ, PyCharm, etc.) |
| **Claude Code web (claude.ai/code)** | Browser-hosted Claude Code sessions |
| **Claude Agent SDK** | Library for building custom agents programmatically on the same runtime Claude Code uses |
| **Claude Code plugins** | Installable bundles of skills/commands/agents from marketplaces (`~/.claude/plugins/`) |
| **MCP (Model Context Protocol)** | Open protocol for connecting external tools/data sources to Claude clients |

## API / platform

| Component | What it is |
| :--- | :--- |
| **Claude API / Anthropic API** | Messages API for direct integration; billed via Anthropic Console |
| **Anthropic Console** | API key management, usage, billing (console.anthropic.com) |
| **Managed Agents** | Server-hosted agents with a managed sandbox, run via the API |
| **Amazon Bedrock / Google Cloud Vertex / Microsoft Foundry** | Third-party cloud platforms that host Claude models, incl. Claude Code access through them |
| **Claude Code Gateway** | Self-hosted gateway (`claude gateway`) for orgs deploying SSO/policy in front of Claude Code |

## Chat integrations

| Component | What it is |
| :--- | :--- |
| **Claude Tag (Claude in Slack)** | Claude accessible directly inside a Slack workspace |

## Cross-cutting features (not standalone products)

| Component | What it is |
| :--- | :--- |
| **Remote Control** | Lets one Claude Code session/device control or view sessions on other machines |
| **Artifacts** | Published, shareable interactive outputs (HTML/code) generated by Claude, viewable standalone |
| **Skills** | Reusable packaged instructions invocable across Claude Code sessions (`~/.claude/skills/`) |
